1. The Four Stages of C Compilation

In low-level software engineering, source code is converted to binary machine instructions through four discrets stages:

  1. Preprocessing: Header expansion, macro substitution.
    Command: gcc -E main.c -o main.i
  2. Compilation: Translation of preprocessed C code into assembly language.
    Command: gcc -S main.i -o main.s
  3. Assembly: Converts assembly instructions into machine-level object code.
    Command: gcc -c main.s -o main.o
  4. Linking: Links object code with system libraries to produce the final executable binary.
    Command: gcc main.o -o main.exe

2. Essential Developer Shortcuts in VS Code

Keyboard combinations required for rapid, efficient editing:

  • Toggle Integrated Terminal: Ctrl + `
  • Open Command Palette: Ctrl + Shift + P
  • Format Document (Prettier): Shift + Alt + F
  • Save All Open Files: Ctrl + K followed by S

3. Core Computer Science Glossary

DOM (Document Object Model)
The in-memory hierarchical tree representation of an HTML document constructed by the browser.
JVM (Java Virtual Machine)
The abstract runtime engine executing Java bytecode, enabling cross-platform portability.

Atomicity, Consistency, Isolation, and Durability—the four fundamental pillars of relational database transactions.
